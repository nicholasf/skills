## Changes

### `ask-foreign-agent/tools/edit_file.py`

Tool name: `edit_file`

Parameters: `path: str`, `old_string: str`, `new_string: str`

Behaviour:
- Resolve path the same way as `read_file` (absolute or relative to `_context.working_directory`)
- Read the file; return an error string if reading fails
- Count occurrences of `old_string` in the content
- If count == 0: return an error saying `old_string` was not found
- If count > 1: return an error saying how many matches exist and asking for more context to make it unique
- If count == 1: replace the single occurrence with `new_string` and write the file; return a confirmation string including the resolved path

Docstring must explain: replaces an exact string in a file; fails if not found or if it matches more than once.

### `ask-foreign-agent/tools/list_directory.py`

Tool name: `list_directory`

Parameters: `path: str = "."`, `max_depth: int = 3`

Behaviour:
- Run `find` with `-maxdepth {max_depth}` on the given path
- Exclude `node_modules`, `.git`, `__pycache__`, `.venv`, and `dist` using separate `-not -path` clauses (find does not accept `|` in path patterns)
- Pipe to `sort`
- Use `_context.run_command` to execute

Docstring must explain: lists directory tree excluding common build/cache directories.

### `ask-foreign-agent/tools/git_diff.py`

Tool name: `git_diff`

Parameters: none

Behaviour:
- Run `git diff && git diff --cached` via `_context.run_command`
- If the output exceeds 6000 characters, truncate to 6000 and append `\n...[truncated]`
- If output is empty or only whitespace, return `"(no changes)"`

Docstring must explain: shows unstaged and staged working-tree changes.

### `ask-foreign-agent/tools/typecheck.py`

Tool name: `typecheck`

Parameters: none

Behaviour:
- Run `cd backend/saga && pnpm tsc --noEmit` via `_context.run_command` with `timeout=60`
- Return the output as-is

Docstring must explain: runs TypeScript compiler on `backend/saga` (no emit); only useful when `--cwd` is the yggd repo root.
